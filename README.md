## Selected work

### [VisionInsight](https://github.com/DrBarga/visioninsight)

A recorded-video analytics application that links metrics and answers to timestamps and source footage. I develop the video-processing pipeline, FastAPI backend, job lifecycle and browser interface.

The repository includes setup instructions, tests and release requirements. The current version is an evaluation release candidate, not a completed commercial launch. Detection and tracking results depend on the footage; representative accuracy and load evaluation remain part of the release work.

### [TraceForge](https://github.com/DrBarga/TraceForge)

A local Windows diagnostics tool built with C#/WinUI 3 and a native C++20 agent. I develop the desktop application and agent integration, including process inspection, a sampled timeline before an application exits, and JSON/HTML reports.

Version 1.0.0 is available on the repository's release page. The README explains platform requirements, data handling and access limitations. An observed exit code provides context; it does not establish the cause of a failure.

### [KeyCRM integration](https://github.com/DrBarga/Integrations-with-KeyCRM)

A TypeScript service for matching products by SKU, synchronizing stock and transferring orders between a storefront and KeyCRM. The implementation keeps product matching explicit and protects order transfer against duplicates.

The README documents the flows, commands and remaining catalog-data dependency. Full catalog synchronization requires consistent SKUs across both systems.
